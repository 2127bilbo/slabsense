### The 0.5 Rule (Primary Algorithm)

**Final grade can only be 0.5 higher than your lowest subgrade.**

Exception: If 2+ subgrades share lowest, final = lowest

#### Examples

| Subgrades (C/Co/E/S) | Final | Explanation |
|----------------------|-------|-------------|
| 10/10/10/9.5 | **10** | Lowest is 9.5, +0.5 = 10 |
| 9.5/9.5/9.5/9 | **9.5** | Lowest is 9, +0.5 = 9.5 |
| 10/10/9/10 | **9.5** | Lowest is 9, +0.5 = 9.5 |
| 9.5/9.5/9/9 | **9** | Two at lowest = equals lowest |
| 9/8.5/8/9.5 | **8.5** | Lowest is 8, +0.5 = 8.5 |

### Grading Algorithm (HOLISTIC)

**Key Philosophy:** Poor centering alone should NOT prevent an otherwise near-mint card from achieving 8.5+.

- NOT strict "lowest factor" like BGS
- Excellent corners/edges/surface CAN compensate for slightly off-centering
- More lenient than BGS on centering relative to other factors

## Implementation Notes

### Converting Between Formats

**Centering: MAX SIDE vs DEVIATION**

```
MAX SIDE = 50 + DEVIATION
DEVIATION = MAX SIDE - 50

Example:
  55/45 ratio = 5% deviation (55 - 50 = 5)
  60/40 ratio = 10% deviation
  48/52 ratio = 2% deviation (|48-50| = 2)
```

### Grading Function Template

```javascript
function getGradeByCompany(company, frontDev, backDev, corners, edges, surface) {
  const thresholds = CENTERING_THRESHOLDS[company];

  // Get centering grade
  const frontGrade = getCenteringGrade(frontDev, thresholds.front);
  const backGrade = getCenteringGrade(backDev, thresholds.back);
  const centeringGrade = Math.min(frontGrade, backGrade);

  // Apply company-specific algorithm
  switch (company) {
    case 'TAG':
      // Compounding: min × 0.75 + avg × 0.25
      const scores = [centeringGrade, corners, edges, surface];
      const minScore = Math.min(...scores);
      const avgScore = scores.reduce((a,b) => a+b) / scores.length;
      return minScore * 0.75 + avgScore * 0.25;

    case 'PSA':
    case 'SGC':
      // Lowest factor
      return Math.min(centeringGrade, corners, edges, surface);

    case 'BGS':
      // 0.5 rule
      const lowest = Math.min(centeringGrade, corners, edges, surface);
      return lowest + 0.5;

    case 'CGC':
      // Holistic - centering can be compensated
      const conditionAvg = (corners + edges + surface) / 3;
      if (conditionAvg >= 9.5 && centeringGrade >= 8) {
        return Math.min(conditionAvg, centeringGrade + 0.5);
      }
      return Math.min(centeringGrade, corners, edges, surface);
  }
}
```

### Priority Order for Missing Data

When data is not available for a company, use this fallback order:

1. **TAG** (gold standard - 507-card calibration)
2. **BGS** (most detailed public documentation)
3. **PSA** (industry leader, updated Q1 2025)
4. **CGC** (holistic approach, less strict)
5. **SGC** (strictest back centering)
