# Fix group 3a — Security and secrets

> **For agentic workers:** executed natively by the app session, task by task, each with its
> test and commit. Closes audit ids listed per task (`docs/audits/2026-10-app-store-audit.md`).

**Goal:** remove the live exposures the audit found without changing any behaviour the rest of
the audit measured: secrets out of the tree, no self-granted credits, no identity from request
bodies, no unauthenticated AI endpoints, no provider routing from the client, honest webhook
accounting.

**Architecture:** no new systems. Files move out of the repo, two SQL policies tighten, two
routes gain `requireUser`, one route is deleted, one handler ignores body fields, one webhook
reorders two statements.

**Spec:** audit section G (`docs/audits/parts/G-security.md`), with B-05, B-13, D-03, F-07,
F-08, M-01.

## Global constraints

- Never print a secret value; move them by file copy, not by echo.
- The owner's uncommitted `scripts/tag-dataset/tagdataset/{cli,download}.py` stay untouched.
- Migrations are applied by the owner in the Supabase SQL editor; the file plus a runbook line is
  the deliverable.
- Rewriting git history on the public remote is a separate owner decision (Task 1, step 9).

## Review focus

1. The foil-border pull runner (`run-pull.ps1`) dot-sources `data/env.ps1`: after the move, the
   TAG signing values must come from that file or every future `fetch` fails. Test: `pytest` with
   the env set, and a dry `python -c "from tagdataset import tagapi; tagapi.make_key('x')"`.
2. The harness scripts read TAG reference photos from the scraper folder; after the move they
   must find them via `SLABSENSE_DATA_DIR`. Test: `node scripts/harness/run.mjs --limit 2`.
3. A signed-in user editing their display name must still succeed after the column grant. Test:
   the migration grants `display_name`, `username`, `preferred_company` explicitly.
4. The slab checkout already authenticates; the change must not double-check and reject it.
5. Webhook duplicate delivery must return 200 and credit once.
