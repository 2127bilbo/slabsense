# Fix group 3b — Payments: one paid product, Apple in-app purchase

> **For agentic workers:** executed natively by the app session. Closes audit ids per task
> (`docs/audits/2026-10-app-store-audit.md`). Owner actions marked. App Store Connect work
> cannot be tested from this repo; the server and client sides are built and unit-tested so the
> first sandbox purchase is a configuration step, not a coding step.

**Goal:** a user in the iOS app can legitimately buy the AI Grade, by subscription allowance or
by pack, through Apple; the ledger follows Apple's server notifications; the web keeps Stripe;
nothing in the native build points at Stripe for a digital good.

**Decisions in force (owner, 2026-10-02):** one paid tier, "AI Grade", built on the Deep flow;
the free tier keeps the software grade. Purchase model: monthly subscription allowance plus
consumable packs (`src/lib/products.js`). Direct StoreKit 2 with Apple's official server library
for verification (no RevenueCat): fewer moving parts and nothing between Apple and our ledger.

**Spec:** audit section B (§7 mapping), A-01–A-03, A-08, I-01, I-02, I-12, K-09, K-12.

## Event table (api/_lib/appleLedger.js, tested)

| Apple event | Ledger |
|---|---|
| client `verify` of a subscription transaction, `SUBSCRIBED`, `DID_RENEW`, `OFFER_REDEEMED` | grant the period allowance once per transactionId into `sub_credits_balance`, `sub_credits_expire_at` = expiresDate, status = plan key |
| `ONE_TIME_CHARGE` / client `verify` of a consumable | grant pack credits once per transactionId into `credits_balance` |
| `EXPIRED`, `GRACE_PERIOD_EXPIRED`, `REVOKE` | status expired; allowance expires by date |
| `DID_FAIL_TO_RENEW` (+`GRACE_PERIOD`) | status grace / billing_retry |
| `REFUND` (either kind) | revoke what is left of that purchase, never below zero; subscription → free |
| `DID_CHANGE_RENEWAL_*`, `RENEWAL_EXTENDED` | renewal date only |

Idempotency: `credit_transactions.external_id` unique (`apple:<transactionId>`); replays return
`duplicate: true`. Spend takes the allowance first, then the pack (`spend_credits` v2).
