# Audit parts

One file per section (A–M) of the App Store readiness audit, written by read-only audit agents
against the checklist in `docs/superpowers/plans/2026-10-01-app-store-readiness.md` Phase 1.
Merged into `docs/audits/2026-10-app-store-audit.md` by the app session. Do not edit the parts
after the merge; fix findings by id in Phase 3.

Finding format (one per bullet, in a table or list):

`<ID> | <Severity> | <file:line or area> | <guideline/principle> | <evidence, one or two sentences> | <proposed fix, one line>`

Severity: **Blocker** = Apple rejects or a user cannot legitimately pay/sign up; **Major** = must fix
before submission; **Minor** = fix in Phase 3 if cheap; **Note** = record only.
